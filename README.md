# Moon

Share your Claude Code sessions with a link.

Moon syncs your Claude Code conversations to the cloud and gives you a shareable URL. As you work, sessions stay in sync automatically.

## Quick Start

```bash
# Install the CLI
npm install -g @crescenthq/moon

# Share your most recent session
moon share
```

Or use directly with `npx`

```bash
npx @crescenthq/moon share
```

## Packages

| Package                                           | Description                              |
| ------------------------------------------------- | ---------------------------------------- |
| [@crescenthq/moon](packages/cli)                  | Command-line tool for sharing sessions   |
| [plugin-claude-code](packages/claude-code-plugin) | Claude Code plugin for automatic syncing |
